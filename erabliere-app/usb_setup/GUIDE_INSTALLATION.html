🍁 Érablière — Guide de la clé USB portable

✅ Objectif : Utiliser le logiciel depuis n'importe quel ordinateur (Windows ou Linux) sans rien installer — branchez la clé, double-cliquez, c'est lancé.

📋 Méthodes disponibles

MéthodeDifficultéRésultatTaille USB
A — Python embarqué Windows ⭐⭐ Dossier avec Python portable inclus ~150 Mo
B — Environnement virtuel Linux ⭐⭐ Dossier avec venv inclus ~80 Mo
C — Exécutable PyInstaller Windows/Linux ⭐⭐⭐ .exe ou binaire autonome, zéro dépendance ~100 Mo

🪟 Méthode A — Windows (Recommandée)

1
Préparez la clé USB
Formatez la clé en exFAT (compatible Windows + Linux) ou FAT32.
⚠️ La clé doit avoir au moins 500 Mo d'espace libre.
2
Lancez le script de création
Sur votre ordinateur Windows (avec connexion Internet) : 
usb_setup\CREER_CLE_USB_WINDOWS.bat
Double-cliquez sur ce fichier. Il va :
  • Télécharger Python embarqué (officiel, python.org)
  • Installer Flask, ReportLab, Pillow automatiquement
  • Copier l'application sur la clé
  • Créer le lanceur LANCER_ERABLIERE.bat
3
Structure sur la clé USB après création 
Clé USB:\Erabliere\
├── LANCER_ERABLIERE.bat   ← Double-clic pour démarrer
├── LANCER_AVEC_CONSOLE.bat ← Version debug
├── LIRE_MOI.txt
├── python\                ← Python portable (ne pas toucher)
│   ├── python.exe
│   └── ...
├── app\                   ← L'application
│   ├── app.py
│   ├── static\
│   └── templates\
└── data\                  ← VOS DONNÉES (sauvegarder!)
    ├── erabliere.db
    └── pdfs\
4
Utilisation quotidienne
  1. Branchez la clé USB
  2. Double-cliquez sur LANCER_ERABLIERE.bat
  3. Le navigateur s'ouvre automatiquement sur http://localhost:5000
  4. Travaillez normalement
  5. Fermez la fenêtre noire (Ctrl+C) pour quitter
  6. Retirez la clé USB en toute sécurité

🐧 Méthode B — Linux / Kubuntu (Recommandée)

1
Trouvez le point de montage de votre clé 
ls /media/$USER/
Le nom de votre clé apparaîtra (ex: MACLÉ, USB8GO)
2
Lancez le script de création 
cd usb_setup
chmod +x CREER_CLE_USB_LINUX.sh
./CREER_CLE_USB_LINUX.sh
Entrez le chemin complet : /media/votre_nom/NOM_CLE
3
Utilisation quotidienne 
cd /media/$USER/NOM_CLE/Erabliere
./LANCER_ERABLIERE.sh
Ou double-cliquez sur Erabliere.desktop depuis le gestionnaire de fichiers.

⚡ Méthode C — Exécutable autonome (.exe / binaire)

Cette méthode crée un exécutable unique qui contient Python + toutes les bibliothèques. L'utilisateur n'a absolument rien à installer, même pas Python.

Sur Windows :

usb_setup\CONSTRUIRE_EXE_WINDOWS.bat
Résultat : dist\Erabliere\Erabliere.exe → copiez ce dossier sur la clé.

Sur Linux :

cd usb_setup
./CONSTRUIRE_BINAIRE_LINUX.sh
Résultat : dist/Erabliere/Erabliere → copiez ce dossier sur la clé.
⚠️ Important : Un exécutable Windows (.exe) ne fonctionne que sur Windows, et un binaire Linux ne fonctionne que sur Linux. Compilez sur chaque OS séparément si vous utilisez les deux systèmes.

💾 Sauvegarde de vos données

⚠️ CRITIQUE : Toutes vos données sont dans le fichier data\erabliere.db.
Une clé USB peut tomber en panne sans avertissement. Sauvegardez régulièrement !

Stratégie recommandée :

  • Hebdomadaire : Copiez le dossier data\ sur votre ordinateur
  • Mensuelle : Copiez sur un second disque ou un service cloud
  • Automatique : Utilisez un script de sauvegarde (voir ci-dessous)

Sauvegarde rapide (Windows) :

:: Copiez dans Mes Documents
xcopy /Y "E:\Erabliere\data\erabliere.db" "%USERPROFILE%\Documents\sauvegarde_erabliere\"

Sauvegarde rapide (Linux) :

cp /media/$USER/MACLÉ/Erabliere/data/erabliere.db ~/sauvegarde_erabliere_$(date +%Y%m%d).db

🔧 Résolution de problèmes

ProblèmeSolution
Le navigateur ne s'ouvre pas Tapez manuellement http://localhost:5000 dans Chrome/Firefox
Port 5000 occupé Dans app.py, dernière ligne : changer port=5000 en port=5001
Antivirus bloque le .exe Ajouter une exception pour le dossier Erabliere\ (faux positif PyInstaller connu)
Erreur "Permission denied" Linux chmod +x LANCER_ERABLIERE.sh puis relancer
Base de données corrompue Restaurer depuis la dernière sauvegarde du fichier erabliere.db
Accès depuis un autre PC sur le réseau Dans app.py : changer host='127.0.0.1' en host='0.0.0.0'

🌐 Accès depuis plusieurs postes (réseau local)

Si vous voulez accéder au logiciel depuis plusieurs ordinateurs en même temps sur votre réseau Wi-Fi/LAN (ex: caisse + bureau) :
  1. Modifiez app.py dernière ligne : host='0.0.0.0'
  2. Lancez le logiciel sur l'ordinateur principal
  3. Sur les autres postes, ouvrez : http://192.168.X.X:5000
    (remplacez par l'IP de l'ordinateur principal)
